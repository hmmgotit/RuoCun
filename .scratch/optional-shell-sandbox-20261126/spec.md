# 可选受管 Shell 沙箱

2026-11-26 用户确认两条交付线。从正式 v2.1.0 制作 v2.2.0 并发布到公开仓库。从已有记忆优化分支应用同一行为，交付本地 2.2.0+memory.1 安装包。

## 决定

- Windows、Linux 和 macOS 的既有受管 Shell 路径默认走常规权限裁决。由用户传入启动参数 `--sandbox` 时，Bash、Monitor 和子代理继承本次运行的系统沙箱模式。
- 已开启时保留 MXC、Bubblewrap 或 Seatbelt 的策略。后端不可用时拒绝该次命令。Windows 额外可写目录只在开启时经用户逐次批准。Write/Edit 使用独立文件权限。
- 已分离的 Windows 后台 Bash 按认证的原计划接回，不改变实际隔离状态。任务列表和 BashOutput 标明原计划状态，无法核实时显示未知。用户可查看日志或请求停止，恢复过程不重跑命令。
- 此决定替代 v2.1.0 的强制 Shell 沙箱及旧无沙箱后台自动退役规则。已提交的旧取消意图和旧文件清理事务按原身份与保留引用收尾。

验收见[实施票](issues/01-optional-shell-sandbox.md)。
